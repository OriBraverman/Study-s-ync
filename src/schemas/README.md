# Schemas Module

This folder contains Pydantic schemas for strict component communication.

## Implemented Core Schemas

- `StudentInputSchema`
- `WeeklyTopic`
- `MissedTopicsSchema`
- `PruningStats`
- `PrunedTopicsSchema`
- `Citation`
- `RetrievedChunk`
- `StudyTaskSchema`
- `BootcampPlanSchema`

## Goal

Ensure predictable, typed outputs between agents and reduce hallucinated structure.
