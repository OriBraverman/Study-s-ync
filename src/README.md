# Source Code Layout

This folder contains the codebase for the ArmorAgent system.

## Current State

- `scraper/`: Active BIU syllabus scraping pipeline (working baseline).
- `agents/`: Planned agent implementations (Syllabus Analyzer, Router, Retrieval, Planner).
- `retrieval/`: Planned vector search and document retrieval layer.
- `orchestration/`: Planned LangGraph/CrewAI flow and routing logic.
- `api/`: Planned FastAPI backend.
- `schemas/`: Planned Pydantic contracts between components.
- `ui/`: Planned frontend app.

Each subfolder has its own README with details and next steps.
