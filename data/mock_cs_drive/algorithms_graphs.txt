Lecture 7: Graph Exploration & Shortest Paths

Key Concepts:
1. Graph Representations: Adjacency List (space O(V+E), efficient for sparse graphs) vs Adjacency Matrix (space O(V^2), O(1) edge check).
2. Search Algorithms:
   - Breadth-First Search (BFS): Explores nodes level-by-level using a Queue. Computes single-source shortest paths on unweighted graphs in O(V+E).
   - Depth-First Search (DFS): Explores recursively along branches, records discovery/finish times. Used for topological sort and cycle detection.
3. Single-Source Shortest Paths:
   - Dijkstra's Algorithm: Requires non-negative edge weights. Greedy strategy using a Min-Priority Queue. Runs in O(E log V) time with binary heaps.
   - Bellman-Ford Algorithm: Handles negative weights, detects negative weight cycles. Runs in O(V E) time by relaxing all edges V-1 times.
4. All-Pairs Shortest Paths:
   - Floyd-Warshall Algorithm: Dynamic programming bottom-up algorithm. Runs in Theta(V^3) time using three nested loops.
