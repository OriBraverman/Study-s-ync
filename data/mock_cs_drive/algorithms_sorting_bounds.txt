Lecture 4: Sorting Lower Bounds & Linear-Time Sorting

Key Concepts:
1. Comparison-based Sorting Lower Bound: In the decision-tree model, any comparison-based sort requires Omega(n log n) comparisons in the worst case because a binary tree with >= n! leaves must have height >= log(n!) = Omega(n log n).
2. Linear-Time Non-Comparison Sorting:
   - Counting Sort: Assumes keys are integers in the range [0..k]. Uses temporary and output arrays to place elements directly in sorted order. Stable, runs in O(n+k) time.
   - Radix Sort: Sorts multi-digit numbers digit-by-digit starting from Least Significant Digit (LSD) to Most Significant Digit (MSD). Requires a stable sorting helper (like Counting Sort). Runs in O(d(n+k)) time.
   - Bucket Sort: Assumes input is uniformly distributed in the interval [0, 1). Divides the interval into n equal-sized buckets, distributes keys, sorts each bucket, and concatenates. Runs in linear average-case time Theta(n).
