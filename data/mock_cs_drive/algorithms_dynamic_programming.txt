Lecture 5: Dynamic Programming & Rod Cutting

Key Concepts:
1. Dynamic Programming (DP) Paradigm: Applied to optimization problems with overlapping subproblems and optimal substructure.
2. Rod Cutting Problem: Given a rod of length n and a price table p_i for pieces of length i, find the maximum revenue r_n obtainable by cutting the rod.
   - Naive Recursive Solution: T(n) = O(2^n) because it repeatedly recalculates the same subproblems.
3. DP Approaches:
   - Top-down with Memoization: Solves recursively but saves each subproblem's result in a lookup table. Runs in O(n^2) time.
   - Bottom-up: Solves subproblems in size order (smallest first), avoiding recursion overhead. Runs in O(n^2) time.
4. Reconstruction of Optimal Solution: By keeping a choice array s[i] representing the optimal size of the first piece cut from a rod of length i, we can reconstruct the exact cuts in O(n) time.
