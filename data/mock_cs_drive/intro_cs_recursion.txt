Introduction to Computer Science – Recursion and Recursive Functions

Recursion is a programming technique in which a function calls itself in order to solve a problem by breaking it into smaller, self-similar subproblems. Every recursive solution requires two components: a base case that terminates the recursion and returns a concrete value, and a recursive case that reduces the problem toward the base case.

The classic example is the factorial function: factorial(n) = n × factorial(n−1), with factorial(0) = 1 as the base case. Another canonical example is the Fibonacci sequence, where fib(n) = fib(n−1) + fib(n−2). Each recursive call is placed on the call stack; when the base case is reached, the stack unwinds and results propagate back up.

Recursive algorithms excel at problems with a naturally recursive structure: tree traversal, directory scanning, merge sort, binary search, and parsing nested expressions. The elegance of recursion comes at a cost — each call consumes stack space, and deep recursion can cause a stack overflow. Python enforces a default recursion limit of 1000 frames.

Tail recursion occurs when the recursive call is the last operation in the function body; some languages optimize this into a loop. Python does not perform tail-call optimization, so iterative solutions are preferred for performance-critical code. Memoization (caching previously computed results) dramatically improves the efficiency of overlapping-subproblem recursions such as Fibonacci, reducing exponential time to linear.

Understanding recursion builds intuition for divide-and-conquer algorithms and dynamic programming, both cornerstones of algorithm design.
