Lecture 2: Functions, Complexity, and Recurrences

Key Concepts:
1. Asymptotic Notations: O (Upper bound), Omega (Lower bound), and Theta (Tight asymptotic bound).
2. Divide-and-Conquer: Split the problem into smaller subproblems of the same type, conquer recursively, and combine solutions. Example: Maximum Subarray Problem solved in O(n log n).
3. Substitution Method for Recurrences: Guess the mathematical form of the solution, then use mathematical induction to find constants and prove the bound.
4. Master Theorem: Solves recurrences of the form T(n) = aT(n/b) + f(n) where a >= 1 and b > 1.
   - Case 1: If f(n) = O(n^(log_b(a) - epsilon)), then T(n) = Theta(n^(log_b a)).
   - Case 2: If f(n) = Theta(n^(log_b a)), then T(n) = Theta(n^(log_b a) log n).
   - Case 3: If f(n) = Omega(n^(log_b(a) + epsilon)) and satisfies the regularity condition (a*f(n/b) <= c*f(n) for c < 1), then T(n) = Theta(f(n)).
5. Linear Recurrence Equations: Solution to homogeneous and nonhomogeneous linear recurrences with constant coefficients using characteristic polynomials.
