Introduction to Computer Science – Loops and Iteration

A loop is a fundamental control-flow construct that allows a block of code to be executed repeatedly without writing it multiple times. In Python, there are two primary loop types: the for loop and the while loop.

The for loop is used to iterate over a sequence such as a list, tuple, string, or range object. The syntax is straightforward: the loop variable takes each value in the sequence one at a time, executing the body for each element. The built-in range() function is commonly used to generate integer sequences, making for loops ideal for counting iterations or indexing into lists.

The while loop continues executing as long as its Boolean condition evaluates to True. It is particularly useful when the number of iterations is not known in advance — for example, reading user input until a valid value is provided or processing data until a sentinel value is encountered.

Both loop types support two important control statements: break exits the loop immediately regardless of the condition, while continue skips the remainder of the current iteration and jumps to the next one. The else clause, unique to Python, executes after the loop finishes normally (without a break).

Common pitfalls include infinite loops caused by a condition that never becomes False, and off-by-one errors when using range(). Nested loops multiply complexity: a loop inside another loop runs its body n×m times, which can lead to performance concerns. Understanding iteration is essential before tackling recursion, list comprehensions, and higher-order functions.
